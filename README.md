# eqcast releases

eqcast sends your keystrokes and mouse to several EverQuest clients at once, on Windows. This repository holds only the downloads; it has no source code.

Get the newest installer or portable zip from the [Releases](../../releases/latest) page. Each release lists what changed, and a SHA-256 for every file.

- Windows 10 or 11, 64-bit. The .NET runtime is included.
- The installer needs no administrator rights and keeps your settings when you upgrade.
- eqcast is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC": choose **More info**, then **Run anyway**.
